# Contributing

Report SDK problems in GitHub issues. Use synthetic data only; never include API keys or patient
information.

The code in `src/` is generated by Fern from `spec/affinity.openapi.json`. Do not edit it by hand.
To change it, change `fern/generators.yml` or `scripts/generate.sh`, or copy a new contract into
`spec/`, then regenerate:

```sh
scripts/generate.sh         # needs Docker, Node and jq
scripts/generate-check.sh   # regenerates and fails on any difference
```

Then build and test with the .NET 8 SDK:

```sh
docker run --rm -v "$PWD":/src -w /src mcr.microsoft.com/dotnet/sdk:8.0 sh -c '
  dotnet build src/Affinity/Affinity.csproj -c Release &&
  dotnet test src/Affinity.Test/Affinity.Test.csproj &&
  dotnet run --project tests/Affinity.Smoke -- webhook'
```

The full smoke test (`dotnet run --project tests/Affinity.Smoke`) calls a real API and needs a
platform Test key in `AFFINITY_API_KEY`. See README.md.
